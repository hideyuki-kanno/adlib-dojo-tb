# アドリブ道場（トロンボーン）

トロンボーンのアドリブ（即興演奏）を練習するためのWebアプリです。Androidのスマホ・タブレットのChromeで動きます。

公開ページ: https://adlib.mongogeso.org/

## できること

- **伴奏で練習**：ピアノ・ベース・ドラムの伴奏、今のコードと次のコードの表示、倍音×スライドポジション盤でのコードトーン表示、マイクでの音程チェック
- **リズム**：易しい順の10段階のリズム課題（まねっこ／いっしょに／ひとりで）、マイクでのタイミング判定
- **楽譜から読む**：コード進行を入力してアナライズ（キー、度数、ii–V–I、おすすめスケール）。写真からの読み取りとClaudeの解説はClaude上で開いたときだけ使えます。

## ホーム画面に置く

Chromeで公開ページを開き、メニューの「ホーム画面に追加」を選びます。

## メモ

- ファイルは `index.html` 1つで動きます（外部はGoogle Fontsのみ）。
- マイクを使うときはイヤホンで伴奏を聴くと判定が正確になります。
